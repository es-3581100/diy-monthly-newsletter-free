🚀 Quick Start Commands

For someone comfortable using a terminal, this is the rough shape of the setup.

# 1. Create your newsletter folder
$ mkdir my-newsletter
$ cd my-newsletter
$ git init

# 2. Add your website files
$ mkdir -p issues
$ touch index.html
$ git add .
$ git commit -m "Initial newsletter setup"

# 3. Create a GitHub repository, then connect it
$ git remote add origin https://github.com/YOU/my-newsletter.git
$ git branch -M main
$ git push -u origin main

# 4. Enable GitHub Pages in the repository settings
✨ Then your site can live at https://YOU.github.io/my-newsletter/
